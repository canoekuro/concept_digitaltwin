# 参照データ

`persona_sim` に同梱する参照テーブル。**ペルソナ本体のデータは置かない**（`personas_base`
は Delta テーブルとして持つ。`SPEC_PHASE1.md` §2.1）。ここに置くのは、調査設計のときに
参照する外部統計だけ。

## `census_population_by_sex_age5.csv`（国勢調査 人口構成比）

Web UI の割り付けパターン「国勢調査人口構成比」で使う（`docs/SPEC_UI.md` §5）。
`persona_sim.uiconfig.census` が読み、対象年齢の範囲で再標準化して
`quotas.mode: proportion` の比率にする。整数人数への配分は行わない
（`persona_sim.panel.quotas.allocate_cell_sizes()` の最大剰余法に委ねる）。

### 列

| 列 | 型 | 内容 |
|---|---|---|
| `sex` | string | `男` / `女`（`personas_base.sex` と同じ値） |
| `age_min` / `age_max` | int | 5歳階級の下限・上限（`20`, `24` など） |
| `population` | int | その階級の人口（人） |

### 出典（**投入時に必ず記入すること**）

| 項目 | 値 |
|---|---|
| 出典 | 総務省統計局「国勢調査」 |
| 取得元 | e-Stat（<https://www.e-stat.go.jp/>） |
| 調査年次 | 令和7年（2025年） |
| 統計表番号 | 第2-1表（人口等基本集計 男女・年齢（5歳階級）別人口） |
| 取得日 | 2026年8月5日 |
| 加工内容 | 男女別・5歳階級別の人口を抜き出し、上記4列に整形したもの。数値の改変は行わない |

政府統計の利用にあたっては出典を明示する。UI の About と出力ファイルにも
出典を表示する（`SPEC.md` §15.3 の CC BY 4.0 帰属表示とは別枠で、両方出す）。

### CSV が無い場合

`load_census()` は `None` を返し、UI は国勢調査パターンを選択不可にする。
数値を持たないまま「人口構成比で割り付けた」と表示する方が害が大きいため、
黙って均等割り付けにフォールバックしない。

サンプル（形式確認用。**実データではない**）:

```csv
sex,age_min,age_max,population
男,20,24,2900000
女,20,24,2800000
```
