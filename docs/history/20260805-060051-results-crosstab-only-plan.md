# 結果閲覧ページをクロス集計表だけにする（計画）

- 日時: 2026-08-05 06:00:51
- 起票: `docs/issues/20260805002.md`
- 対象: 結果閲覧ページ（`app/views/results.py`）と、その材料になる集計・出力の純関数

## 1. 目的

結果閲覧ページから解釈の入る表示（グラフ・カード）を外し、**クロス集計表だけ**にする。
あわせてダウンロードを1ボタンに集約し、ローデータを人が読める形にする。

## 2. 起票文書の破損について

`docs/issues/20260805002.md` は貼り付け事故で1〜7行目が重複していた。

- 1〜3行目 = 4〜6行目（同一）
- 4行目が途中で切れ、1行目の末尾断片（`ひス集計表だけにする。具体的には…`）に接続
- 7行目が本来の完全版

内容の欠落は無く、重複を除けば意図は復元できる。本作業で重複を除去し、
確認結果を同ファイルに追記する。

### 決めたこと（ユーザー確認済み）

- **ダウンロードは xlsx 1ファイルに同梱**する。`st.download_button` は1ファイルしか返せないため。
  集計表シートとローデータシートの2枚構成にする。
- **集計表シートは「設問」列を足して縦に積む。** 2問は選択肢ラベルが異なるので、
  選択肢列は番号のみ（`選択肢1`〜`選択肢N`）にし、ラベルは表の上の凡例行で設問ごとに示す。

### 不変条件との衝突（`AGENTS.md`）

「シート1枚のみ」にすると、概要シートに載せていた E3/E4 の注記（品質フラグ率・
割り付け外セルの混入）が消える。**注記は必ず表面化させる**のが不変条件なので、
集計表シートの先頭に注記行として残す。シートは増やさない。

### 設計方針

- **集計の算術は一切書き足さない。** 新しい表はすべて `result.crosstabs`（`compute_metric`
  を通った値）の並べ替えとして作る。CLI と UI で数字が食い違う余地を作らない。
- **`write_xlsx()` と `write_outputs()` は変更しない。** CLI の `report.xlsx` の中身を
  UI 都合で変えない。
- ローデータの選択肢ラベルは `to_defined_codes()` で**定義順に戻してから**引く。
  今の2問は `randomize_options: false` だが、飛ばすとシャッフルした設問でラベルがずれる。

## 5. 検証方法

- `./scripts/run-tests.sh`（非 Spark、現状 473 件が緑）
- 追加するテスト
  - コンセプト軸の表の表頭・行順・値が `crosstab_table` と一致すること
  - 積み上げシートに2問ぶんの行が入り、選択肢列が最大選択肢数に揃うこと
  - 注記（E3/E4）が集計表シートに残ること
  - ローデータにコンセプト名と選択肢ラベルが入ること、提示順→定義順の読み替えが効くこと
  - 属性別クロス集計の選択肢が `crosstab_*` だけになること
- `write_xlsx()` の既存テストが変わらず通ること（CLI 出力を壊していない証拠）
